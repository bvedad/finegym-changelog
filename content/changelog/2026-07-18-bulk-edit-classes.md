---
title: "Bulk Edit Classes"
date: "2026-07-18"
categories: ["Admin", "Scheduling"]
---

You can now change the time or coach of many upcoming classes at once, instead of editing them one by one. Open any class and choose **Bulk edit schedule** to get started.

- **Filter by criteria** — Select the classes to change by class type, day of week, current start time, and coach
- **Live match count** — See exactly how many classes will change, and expand the list to review them before applying
- **Change time or coach** — Move classes to a new start/end time, reassign the coach, or remove the coach entirely
- **Past classes protected** — Past and already-started classes are never affected, and reservations move with the class automatically

For more details, see the [Bulk Editing Classes guide](https://docs.finegym.io/admin/bulk-editing-classes).
